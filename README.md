# АРМ «Сопровождение конкурсов на соискание грантов» (Rust)

**Дисциплина:** Системы управления базами данных  
**Кафедра:** Управления и интеллектуальных технологий (УИТ), НИУ «МЭИ»  
**Вариант:** № 7  
**Авторы:** студенты группы А-03-23, бригада 4 (Грудинин Е.К., Степанищев В.Р., Криштул А.Н.)  
**Преподаватель:** доцент Полотнов М.М.

Полная реализация информационной системы на языке **Rust**. Проект объединяет базу данных SQLite, расчетный финансовый модуль, генератор аналитических отчетов и два интерфейса: современный графический интерфейс (GUI) на базе `eframe`/`egui` и интерфейс командной строки (CLI) на базе `clap`.

---

## Возможности системы

1. **Реестр проектов НИР:**
   - Интерактивный просмотр 400 проектов с сортировкой по первичному составному ключу `(codkon, codproj)`.
   - Добавление проектов с автоматическим предложением следующего шифра (`MAX + 1`).
   - Валидация формата кодов ГРНТИ (`XX.XX.XX`) и проверка уникальности ключа.
   - Редактирование и удаление записей с автоматической синхронизацией агрегатов конкурсов.

2. **Справочники конкурсов и вузов:**
   - 17 конкурсов грантов со сводными финансовыми показателями (план, факт, квартальные выплаты Q1–Q4, число проектов).
   - 342 организации высшего образования с географической привязкой (федеральный округ, субъект РФ, город, ведомство).

3. **Многокритериальная фильтрация:**
   - Фильтрация по конкурсу грантов.
   - Каскадный географический отбор: Федеральный округ → Субъект РФ → Город → Вуз.
   - Сквозное применение фильтра к реестру проектов и аналитическим срезам.

4. **Аналитические отчеты (3 формы):**
   - **Форма 1:** Распределение проектов по конкурсам (с подсчетом общего числа уникальных вузов).
   - **Форма 2:** Распределение проектов по вузам-исполнителям (с подсчетом уникальных конкурсов).
   - **Форма 3:** Распределение проектов по субъектам РФ.
   - Экспорт отчетов во все поддерживаемые форматы: **XLSX (Excel)**, **HTML**, **CSV**, **TXT**.

5. **Модуль финансирования (Лабораторная работа № 4):**
   - Сводная панель агрегатов (201 270 000 руб. плана, 70 участвующих вузов, 400 проектов).
   - Расчет предварительного транша по проценту или заданной сумме.
   - Пропорциональное распределение с округлением до целого рубля (Banker's rounding) и группировкой выплат по вузам.
   - Экспорт проекта распоряжения о финансировании.
   - Транзакционное проведение транша в БД SQLite (`fin_qX` + `fact_fin`).
   - Изолированный сброс/обнуление финансирования выбранного квартала.

## Сборка и запуск

### Требования
- Компилятор Rust 1.75+ (`rustc`, `cargo`).
- ОС Windows 10/11 (x64) или Linux / macOS.

### Запуск графического интерфейса
```bash
cargo run --release
# либо двойным кликом на run.bat
```

### Запуск командной строки (CLI)
```bash
# Справка по всем командам
cargo run --release -- --help

# Текущее состояние финансирования
cargo run --release -- finance summary

# Расчет транша 25% за 1-й квартал
cargo run --release -- finance calc --percent 25.0 --quarter 1

# Экспорт аналитического отчета по конкурсам в Excel
cargo run --release -- report --form contest --export otchet.xlsx

# Реестр проектов НИР по конкурсу № 1
cargo run --release -- projects --contest 1 --sort-key
```

### Запуск тестов
```bash
cargo test
```
Все тесты проверяют бизнес-логику на изолированных временных копиях базы данных через SQLite backup API, гарантируя неизменность рабочей БД.
